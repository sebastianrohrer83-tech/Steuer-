# Lernjournal – Ordni

**Dieses Repo ist öffentlich.** Schreibe nur technische Erkenntnisse hierher. Keine Zugangsdaten, keine echten Belege oder Steuerdaten, nichts Persönliches, keine Geschäftsinterna.

Jeder Agent trägt hier nach jeder Aufgabe einen Eintrag ein und liest vor jeder Aufgabe die letzten Einträge seines Bereichs. Neueste Einträge oben.

Format:

```
## JJJJ-MM-TT · Agent · Aufgabe
- Lief gut:
- Wurde korrigiert:
- Nächstes Mal anders:
- Vorschlag zur Anweisung (falls ein Fehler zweimal vorkam):
```
