# Lernjournal

Jeder Agent trägt hier nach jeder Aufgabe einen Eintrag ein und liest vor jeder Aufgabe die letzten Einträge seines Bereichs. Neueste Einträge oben. Keine Zugangsdaten, Kundendaten oder Persönliches.

Format:

```
## JJJJ-MM-TT · Agent · Aufgabe
- Lief gut:
- Wurde korrigiert:
- Nächstes Mal anders:
- Vorschlag zur Anweisung (falls ein Fehler zweimal vorkam):
```

Wöchentlicher Lernreview: Muster erkennen, die drei wichtigsten Verbesserungen Sebastian vorlegen.
